`no-script.stoverride` 是 2026-09-17 从主文件生成的临时诊断快照，不参与每日构建。来源 SHA256 记录在文件开头。

它只移除 58 条 JavaScript 触发规则及 9 个脚本提供者，并修改说明。全部分流、MITM、原生正文重写、URL 重写和静态响应均与生成时的主文件一致。它用于定位开销，不是正式替代版本。

1. 停用主覆写及之前导入的独立增强，单独启用此文件。
2. 停止后重新启动 Stash 代理，避免沿用上一轮连接和运行状态。
3. 按同样顺序打开抖音、微博并浏览相同内容，记录内存峰值及退出应用一分钟后的值。
4. 与无覆写时约 20 MB、完整覆写时抖音约 37 MB / 微博约 48 MB 对照。一次测试只能初步定位，流量和内容差异也会影响结果。

若关闭脚本后明显降低，优先检查脚本执行；若仍接近完整覆写，下一步检查 MITM 和原生正文重写。两个覆写不要叠加启用；测试完成后可移除此文件。
